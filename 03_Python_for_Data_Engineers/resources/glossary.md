# Glossary

Terms used in Module 03, in alphabetical order, with the topic where each is explained.

| Term | Meaning | Topic |
|---|---|---|
| **Abstract class** | A class that cannot be instantiated and declares methods subclasses must implement (`abc`) | [15](../15-oop-inheritance-and-abstraction.md) |
| **Anaconda** | A distribution bundling Python, `conda`, Jupyter and data libraries | [01](../01-introduction-to-python-for-data-engineering.md) |
| **Argument** | The value passed to a function when it is called | [12](../12-functions-i.md) |
| **Class** | A blueprint that defines the attributes and methods of its objects | [14](../14-oop-classes-and-objects.md) |
| **Comprehension** | A compact expression that builds a list, set or dictionary from an iterable | [11](../11-for-else-while-else-and-comprehensions.md) |
| **Constructor** | The `__init__` method that sets up a new object | [14](../14-oop-classes-and-objects.md) |
| **Context manager** | An object used with `with` that sets up and cleans up, such as a file | [17](../17-file-handling-and-exception-handling.md) |
| **Dictionary** | A mutable collection of unique keys mapped to values | [06](../06-dictionary.md) |
| **Duck typing** | Using an object by the methods it has, not by its class | [16](../16-oop-polymorphism-and-encapsulation.md) |
| **Dynamic typing** | A variable's type comes from the value it holds at run time | [01](../01-introduction-to-python-for-data-engineering.md) |
| **Encapsulation** | Keeping data inside an object and guarding access through methods | [16](../16-oop-polymorphism-and-encapsulation.md) |
| **Environment** | An isolated Python installation with its own packages | [01](../01-introduction-to-python-for-data-engineering.md) |
| **Exception** | An error raised at run time that can be caught with `try/except` | [17](../17-file-handling-and-exception-handling.md) |
| **f-string** | A string literal starting with `f` that evaluates expressions in `{}` | [07](../07-strings-i.md) |
| **Function** | A named, reusable block of code that can take inputs and return a result | [12](../12-functions-i.md) |
| **Identifier** | The name given to a variable, function or class | [02](../02-literals-keywords-and-data-types.md) |
| **Immutable** | Cannot be changed after creation: `int`, `str`, `tuple` | [06](../06-dictionary.md) |
| **Inheritance** | A class taking the attributes and methods of a parent class | [15](../15-oop-inheritance-and-abstraction.md) |
| **Jupyter notebook** | An interactive document of code and text cells | [01](../01-introduction-to-python-for-data-engineering.md) |
| **Kernel** | The Python process behind a notebook | [01](../01-introduction-to-python-for-data-engineering.md) |
| **Lambda** | A small anonymous function written as one expression | [13](../13-functions-ii.md) |
| **LEGB** | Name lookup order: Local, Enclosing, Global, Built-in | [13](../13-functions-ii.md) |
| **List** | A mutable, ordered collection | [04](../04-lists-and-intro-to-for-loops.md) |
| **Method** | A function that belongs to an object or class | [14](../14-oop-classes-and-objects.md) |
| **MRO** | Method Resolution Order: the order classes are searched for an attribute | [15](../15-oop-inheritance-and-abstraction.md) |
| **Mutable** | Can be changed after creation: `list`, `dict`, `set` | [06](../06-dictionary.md) |
| **Object** | An instance of a class | [14](../14-oop-classes-and-objects.md) |
| **Parameter** | The name in a function definition that receives an argument | [12](../12-functions-i.md) |
| **Polymorphism** | The same call behaving differently depending on the object | [16](../16-oop-polymorphism-and-encapsulation.md) |
| **Property** | A method used like an attribute, often for validation (`@property`) | [16](../16-oop-polymorphism-and-encapsulation.md) |
| **Rerun model** | Streamlit running the whole script again on each interaction | [18](../18-streamlit.md) |
| **Set** | A mutable collection of unique, unordered values | [05](../05-tuples-and-sets.md) |
| **Slice** | A part of a sequence, written `[start:stop:step]` | [04](../04-lists-and-intro-to-for-loops.md) |
| **Tuple** | An immutable, ordered collection | [05](../05-tuples-and-sets.md) |
| **Type-casting** | Converting a value to another type, such as `int("5")` | [07](../07-strings-i.md) |
| **Virtual environment (`venv`)** | Python's built-in way to make an isolated environment | [01](../01-introduction-to-python-for-data-engineering.md) |
